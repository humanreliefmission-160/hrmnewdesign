-------------------------------- DATABASE STRUCTURE --------------------------------
Donation
  - ID [Primary Key]
  - Donation ID (auto generated)
  - Donation Type [Monthly, One Off]
  - Donation [Donation Id]
  - Amount [Amount]
  - Intention [Intention]
  - Gift Aid [Gift Aid - Yes/No]
  - Donation status [Pending, Completed, Failed]

Donor
  - ID [Primary Key]
  - Name
  - Email [Unique]
  - Phone
  - Address
  - Foreign Key(Donation.Donation Id)
  - Newsletter Subscribe [Yes/No] (Marketing Subscription Foreign key)

Location
  - ID [Primary Key]
  - Name
  - Description
  - Co ordinates [for map]
    > Longitude
    > Latitude
  - Projects (Foreign Key(Project.Location.Id))
  - Created At [Date]
  - Created Time [Time]

Project
  - Project Id
  - Project [project name]
  - Project Category [project category name]
  - Ecosystem Stage
  - Location (Foreign Key(Location.Location.Id))

Payment
  - Payment ID [Primary Key]
  - Amount [Amount]
  - Payment method [Card, Paypal, Google Pay]
  - Frequency [Monthly, One Off]
  - Payment status [Pending, Completed, Failed]
  - Payment date [Date]
  - Payment time [Time]
  - Payment currency [Currency]
  - Donation [Donation Id, Foreign Key(Donation.Donation Id)]

  Marketing Subscription
  - ID [Primary Key]
  - Name
  - Email
  - Phone
  - Subscription [Active, Unsubscribed]
  - Unsubscribe Date [Date]
  - Unsubscribe Time [Time]
  - Created Date [Date]
  - Created Time [Time]
